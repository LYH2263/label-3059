# 桔子人才 HR 移动端后台管理系统

基于 React + Vite + Express + LowDB 的企业级招聘管理平台。

## 🚀 项目功能
- **仪表盘**: 实时招聘进度、数据趋势。
- **邀约记录**: 候选人状态追踪与管理。
- **面试管理**: 在线面试频道、实时结论设置（通过/不通过）。
- **岗位管理**: 岗位发布、编辑、上下架。
- **数据看板**: 个人、团队及面试数据的多维度可视化分析。
- **通讯录**: 系统通知与客服互动功能。

## 🛠 技术栈
- **Frontend**: React 18, Vite 5, Lucide-React, Chart.js, Framer Motion.
- **Backend**: Express, JWT Authentication, LowDB.
- **Deployment**: Docker, Docker Compose, Nginx.

## 📦 部署说明
1. 确保安装了 Docker。
2. 运行 `docker-compose up -d --build`。
3. 访问 `http://localhost:3059`。
